# 🔐「O中の封印を解け！」謎解きサイト

8/9（日）親子学び祭「全体レクリ（脱出ゲーム）」用の、QR連動謎解きWebサイトです。
静的サイト（GitHub Pages）＋ Google Apps Script（GAS）＋スプレッドシートで動きます。
サーバーの常時運用は不要・すべて無料枠です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 参加者用トップ（チーム登録・進捗★表示・番号手動入力） |
| `point.html` | 謎画面（QRの飛び先。鍵謎→正解後に在り処謎を表示） |
| `dashboard.html` | 運営用ダッシュボード（全チームの現在地・進捗・ヒント状況を一覧、10秒ごと自動更新） |
| `js/puzzles.js` | **謎データ**（問題文・4択・正解・鍵の数字・ヒント・在り処謎）。差し替えはこのファイルだけでOK |
| `js/config.js` | サイト設定（GASのURL・自動ヒントの秒数など） |
| `js/store.js` | 進捗の保存（スマホ内）とGASへの送信 |
| `css/style.css` | デザイン |
| `gas/Code.gs` | GASバックエンドのコード（スプレッドシートに貼り付けて使う） |
| `tools/qr.html` | 設置用QRコードの一括生成・印刷ツール（運営用） |

## セットアップ手順（全部で15分くらい）

### 1. GAS（データ保存先）のセットアップ — コピペ4ステップ

1. [Googleスプレッドシート](https://sheets.new) を新規作成し、名前を「封印を解け_記録」などにする
2. メニューの **拡張機能 → Apps Script** を開き、最初から入っているコードを全部消して、
   このリポジトリの `gas/Code.gs` の中身を丸ごと貼り付ける
3. コード冒頭の `ADMIN_KEY = "oyakomanabi"` を**自分だけが知る合言葉に変更**して保存（Ctrl+S）
4. 右上の **デプロイ → 新しいデプロイ** を押し、
   - 種類の選択（⚙アイコン）→ **ウェブアプリ**
   - 「次のユーザーとして実行」→ **自分**
   - 「アクセスできるユーザー」→ **全員**
   - デプロイを押す（初回は「アクセスを承認」でGoogleアカウントの許可が必要。
     「このアプリは確認されていません」と出たら「詳細」→「（無題のプロジェクト）に移動」で進めてOK）
   - 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/～/exec`）をコピー

> ⚠️ `Code.gs` を修正したときは、**デプロイ → デプロイを管理 → ✏編集 → バージョン「新バージョン」→ デプロイ** をしないと反映されません（URLは変わりません）。

### 2. サイト側の設定

`js/config.js` の `GAS_URL: ""` に、↑でコピーしたURLを貼り付ける。

```js
GAS_URL: "https://script.google.com/macros/s/XXXX/exec",
```

### 3. GitHub Pages で公開

1. GitHubのリポジトリページ → **Settings → Pages**
2. Source を「Deploy from a branch」、Branch を公開したいブランチ・`/(root)` にして Save
3. 数分後に `https://ユーザー名.github.io/ManabiMatsuri/` で公開される

### 4. QRコードの印刷

公開したサイトの `tools/qr.html` をPCで開き、サイトのURLを入力して「生成」→「印刷」。
5か所分のQRコード（手動入力用の番号つき）がまとめて印刷できます。

### 5. 動作確認

- スマホで公開URLを開く → チーム登録 → QR（または番号入力）で謎画面 → 正解 → ★が増える
- PCで `dashboard.html` を開き、合言葉（ADMIN_KEY）を入れる → テストしたチームが表示されればOK
- スプレッドシートの `events` シートに記録が増えていることも確認

## 謎の差し替え方法

`js/puzzles.js` を開き、各ポイントの以下を書き換えるだけです（コードの知識は不要）：

- `question` … 鍵謎の問題文（`\n` で改行）
- `choices` … 4択の選択肢（4つ。数字の1〜4で統一）
- `answerIndex` … 正解の番号（0=1, 1=2, 2=3, 3=4）。正解時に表示される「鍵の数字」は `choices[answerIndex]` の値がそのまま使われる（③大謎の計算で使う数字）
- `smallHint` … 小ヒント（答えに直結しない手がかり程度に）
- `arikaImage` … 在り処謎の画像（次の場所への誘導。鍵謎に正解するまで表示されません。テキストの説明文はなし・画像のみ）

画像を使いたい場合は `images/` フォルダに `KeyA.png`〜`KeyE.png`（鍵謎の画像）、`PlaceA.png`〜`PlaceE.png`（在り処謎の画像）を入れる。

## 当日の運用

- **スタートの流れ**：①オープニングで小謎プリントを配布 → ②解けた参加者が運営に提出 → ③運営が**スタートQR**（`tools/qr.html`で印刷、①〜⑤の5種をランダムに）を渡す → ④読み込むと「手紙の続き」＋最初の在り処謎が表示される
- **参加者**：在り処謎の場所へ → QR読み取り → 謎を解く → 在り処謎で次へ → 5つ集めて封印解除
- **運営**：`dashboard.html` を開いておく
  - 🔴 赤い行 ＝ 未クリアの謎でヒントを見ているチーム。「◯◯で12分経過」のように表示されるので、長いチームから様子を見に行く（仕様どおり、システムからの強制ネタバレはありません）
  - 現在地は「最後に読み取ったQRの場所」です
- **ヒント**：ヒントボタン押下のほか、謎画面を開いて **3分**（`config.js` の `AUTO_HINT_SECONDS` で変更可）経つと小ヒントが自動表示されます
- **QRが読めない参加者**：トップページの番号入力（1〜5）から同じ謎に入れます
- **謎の内容だけ確認したいとき（デバッグ用）**：チーム登録なしで `point.html?p=番号&debug=1` を直接開くと表示できます（例：`point.html?p=3&debug=1`）。記録は一切送信されません
- **本番前にデバッグ機能を一括オフにする**：`js/config.js` の `DEBUG_ENABLED: true` を `false` に変えるだけで、`?debug=1` によるプレビューや `final.html` の「デバッグ用」ボタンなど、サイト全体のデバッグ機能が使えなくなります（コードの他の部分は一切触らなくてOK）

## データについての注意

- 進捗は各スマホの localStorage にも保存されるため、**通信が不安定でも参加者のプレイは止まりません**（記録の送信は非同期・失敗しても無視して続行）
- 氏名を含む記録はスプレッドシートに残ります。**イベント終了後にスプレッドシートを削除**してください（事前説明済みの個人情報対応）
- 4択の正解は `js/puzzles.js` に平文で入っています。ブラウザのソース表示で見ようと思えば見えますが、校内イベントの性質上、許容範囲としています（気になる場合は相談してください）

## ③大謎（最後の謎）— `secret.html`

扉の謎（`final.html`）をクリアすると、4通目の手紙の下に
**「→ 「学校の秘密」を探しに行く」** ボタンが出て、この画面に進みます。
5つの鍵がそろうと扉謎のボタンが出るのと同じ仕組みです。

Xも答えを知らない謎、という設定なので、参加者がその日見つけたものを
合言葉として入力します。

合言葉は**ふたつ**あります。「親子」と「学校」が手を取り合うことが
何より大事、というのがこのイベント全体のテーマなので、片方だけでは開きません。

`js/puzzles.js` の

```js
const SECRET_WORDS = [
  { label: "ひとつめの合言葉", answers: ["おやこ", "親子"] },
  { label: "ふたつめの合言葉", answers: ["がっこう", "学校"] },
];
```

がその答えです。`answers` に書いた表記はどれでも正解になります。
判定は `checkSecretAnswers()` が行い、次のゆれを吸収します。

- ひらがな・漢字・カタカナ（「おやこ」「親子」「オヤコ」すべて可）
- スペース、全角/半角
- **入力する順番**（どちらの欄にどちらを入れても正解）

同じ言葉をふたつの欄に入れた場合は不正解になります。
片方だけ合っているときは「……片方は合ってる。もうひとつは？」と返します。

- ひとつめ「おやこ」… パンフレットを手紙に重ねる謎の答え
- ふたつめ「がっこう」… もうひとつの謎の答え（謎の中身は未確定）

ヒントは `SECRET_HINT`、入口のXのことばは `SECRET_CHALLENGE_MESSAGE`、
クリア時のことばは `SECRET_SUCCESS_MESSAGE`、
そのあとに出る最後の手紙は `EPILOGUE` です。
