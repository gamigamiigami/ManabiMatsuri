⚠ 記録の集計プログラム（GAS）が古いままです。

このままでも鍵あつめの5問はふつうに動きますが、 「扉の謎」と「最後の謎」の段階が出ません（そこにいるチームも「扉の謎」まででしか表示されません）。 本番までに、下の手順で貼り替えてください。

  1. スプレッドシートを開き、拡張機能 → Apps Script
  2. 中身を全部消して、gas/Code.gs を丸ごと貼り付けて保存
  3. 冒頭の ADMIN_KEY が、いま使っている合言葉のままか確認
  4. デプロイを管理 → 鉛筆マーク → バージョン：新バージョン → デプロイ

4番は「新しいデプロイ」ではなく「デプロイを管理」を選んでください。 こちらならURLが変わらないので、js/config.js を直す必要がありません。
「新しいデプロイ」で作ってしまうとURLが変わり、サイトは古いほうを見たままになります。 その場合は新しいURLを js/config.js の GAS_URL に貼り替えてください。
貼り替えが済むと、この枠は自動で消え、上の表示が「集計プログラム v3 ✔」になります。

🔴 赤い行＝まだ解けていない謎でヒントを見ているチーム（経過が長いほど困っている可能性大）。 優先的に様子を見に行ってください。緑＝最後の謎まで解いた完全クリア。
クリア状況は 鍵あつめ（★の数）→ 扉の謎 → 最後の謎 の3段階です。月・鍵は「最後の謎」と並ぶ段階ではなく、 その中にある2つの仕掛け（サブ項目）なので、「最後の謎」の下にぶら下げて表示しています。
✔ 時刻 が解けた時刻、「挑戦中」はその段階に来ているがまだ、 「─」はそこまで来ていないという意味です。
月・鍵の 🌙🔑 は、 最後の謎の2つの仕掛けをホームで見つけたかどうか（薄い印はまだ見つけていない）。 片方だけで止まっているチームがここで分かります。
いまどこは、そのチームがいま取り組んでいる段階（上段）と、 次に向かう段階（下段・薄字）の2行です。
