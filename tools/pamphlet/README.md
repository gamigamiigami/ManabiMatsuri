# ハンドオフ：親子学び祭パンフレット（A4三つ折り両面）

## 概要
O中学校「親子学び祭」のイベント用A4三つ折りパンフレット。A面（おもて）3パネル＋B面（うら）2パネルの構成。Claude Codeで編集しやすいようにレイヤー・パーツごとに分離した構造で提供。

## デザインファイルについて
このバンドルに含まれるHTMLファイルは**デザインリファレンス**です。実装先の環境（React等）に合わせて再構築してください。`reference.html` が元デザインのフラットHTML、`pamphlet.html` がレイヤー分けされた編集用HTMLです。

## Fidelity
**High-fidelity（ハイファイ）** — 色・タイポグラフィ・余白・装飾すべて最終デザイン。ピクセル単位で再現してください。

### 謎の色を変える

矢印と、手紙の中の目印の文字は同じ色にしてある。重ねたとき
「矢印の先が同じ色の文字」になり、合っているか一目で分かるため。

- `tools/pamphlet/pamphlet.html` の `--mark`（矢印）
- `letter.html` の `--mark`（手紙の目印）

**この2つは必ず同じ値にすること。** 片方だけ変えると、
重ねたときの手がかりが消える。

同じ色の文字は答えの3文字以外にもばらまいてあり、色をたどっても
言葉にはならない。順番を決めるのは矢印だけ。手紙の藍色の文字は
完全なかく乱で、謎には関係しない。

### 折り目の位置を調節する

`pamphlet.html` の先頭にある2つの値で、三つ折りの折り目の位置を決めている。

```css
--fold-1: 640px;    /* 1本目＝99mm。謎の折り目。動かさないこと */
--fold-2: 1306px;   /* 2本目。三等分なら1280px。ここは見た目だけ */
```

プリンタが「印刷可能な範囲に縮小」して刷ると、紙の上では版面全体が
少し小さくなる。左端は合っていても右へ行くほどズレが積もるので、
**2本目の点線が折り目より左に来る**。そのときは `--fold-2` を右へ寄せる。

- 目安：紙の右端にできた余白の幅の **2/3** だけ足す
  （余白6mm → 4mm ＝ 26px を足して 1306px）。**1mm = 6.4646px**
- 直したら PDF を作り直す
- `--fold-1` は「パンフレットを手紙に重ねる謎」の折り目そのもの。
  ここを動かすと `solve_overlay.py` の `EDGE_X_PX` も直して
  座標を出し直さないと、謎が成立しなくなる
- 裏面の折り目はこの値から自動で計算される（紙をめくると左右が反転する）

### 印刷時の注意（重要）

A1面（運営からのメッセージ）の右辺＝三つ折りの折り目に、
「パンフレットをスマホ画面に重ねる謎」の魔法陣が2つ、半分だけ印刷されている。
**印刷の縮尺が設計どおりでないと謎が解けなくなる。**

- 拡大縮小は必ず **100%（実際のサイズ）**。「用紙に合わせる」は使わない。
- 用紙は **A4・横**、両面。
- **フチなし印刷は不要。** 魔法陣は紙の端ではなく三つ折りの折り目
  （左端から99mm）にあるので、余白が出るプリンタでも欠けない。
- 切る作業・追加で折る作業は**一切不要**。いつもどおり三つ折りにして配ればよい。
- 設計値：2つの魔法陣はどちらもインク直径 約17.0mm、
  中心間 62.0mm。印刷後に定規で測って確認できる。

### 参加者の手順

1. パンフレットを開き、**A1面（運営からのメッセージ）だけが見えるように
   折り返す**（A2・A3をうしろへ）。折り目は三つ折りの折り目そのもの。
2. その折り目を、スマホに映したXの手紙の魔法陣に重ねる。紙は左下側、
   文字が右上側に見えるように、約52°傾けて置く。
3. 2つの魔法陣がそれぞれ「1つの完全な図形」に見えるよう、
   位置・角度・画面の拡大率を合わせる。
4. 矢印がさす3文字を、折り目に沿って**下から順に**読む → 「おやこ」

> **スタッフ向けの見どころ**：答えの3文字（こ・や・お）は、パンフレットの
> 矢印と**同じ藍色**になっている。うまく重なると「矢印の先が藍色の文字」に
> なるので、小さい画面でも当たりが分かる。ただし藍色の文字は手紙のあちこちに
> あり（色をたどっても「学こみや笑お勉思ろ」としか読めない）、かく乱用の
> 朱色も混ぜてある。順番を決めるのは矢印だけ。
> 手が止まっているチームには「矢印の先の色を見てごらん」と声をかけるとよい。

## 重ね合わせの謎の座標を作り直す

図形の位置・大きさ・手紙の文面を変えたら、必ず次の手順でやり直すこと。
数値を手で書き換えると、矢印が別の文字を指すようになる。

### 1. 手紙の文字の位置を測り直す（文面を変えたときだけ）

```bash
node tools/pamphlet/measure_chars.mjs           # 今の値と比べるだけ
node tools/pamphlet/measure_chars.mjs --write   # letter_chars.json を更新
```

`tools/pamphlet/letter_chars.json` は、手紙を実際に描画して測った全文字の
位置。**封筒を開いた状態**で測ること（閉じたままだと行間が違い 0.015 ずれる。
スクリプトは開いてから測っている）。画面幅 360/390/412/430px の平均をとって
おり、端末間の差は最大 0.003 しかない。

> ⚠️ **手紙の行数を変えると、この謎はほぼ確実に作り直しになる。**
> 手紙は枠に収まるよう自動で縮むので、1行増やしただけで文字が小さくなり、
> 3文字を結ぶ線の角度も長さも変わる。実際、制限時間のくだりを足したとき
> 角度は 44.27° → 38.02° に変わり、魔法陣の大きさと位置を取り直した。
> 文面をいじったら、必ず 1 → 2 → 3 の手順を最後まで通すこと。

文面をいじっていないのに差が出たら、レイアウトを壊す変更が入っている。
たとえば目印の色づけ（`letter.html` の `MARKS`）を足したときは、差が
0.0001 未満＝文字は動いていないことをこれで確かめた。

### 1a. 使う図形（2種類の魔法陣）

折り目に並ぶ2つの図形は、**どちらも魔法陣**です。骨格が違うので、
半分に切れていても「どちらの半分か」がひと目で分かります。

| 名前 | 見た目 | 位置 |
|---|---|---|
| `magicCircle` | 六芒星（三角形が2枚）＋二重の外周 | 折り目の上側 |
| `magicCircle2` | 五芒星＋破線の輪＋頂点の小円 | 折り目の下側 |

どちらも `js/letter-decor.js` の `MOTIFS` が唯一の定義です。手紙は同じ SVG を
CSS 背景として描き、パンフレットは同じ絵から焼いた PNG を刷るので、
**SVGをどこかに書き写さないこと。**絵を変えたときは:

```bash
node tools/motifs/render_motif.mjs        # PNG を焼き直す（薄い版と -bold 版）
python3 tools/pamphlet/measure_ink.py     # INK / INK_PNG を測り直して貼る
```

`measure_ink.py` の出力を `solve_overlay.py` の `INK` / `INK_PNG` に貼ってから、
下の 2 → 3 に進みます。PNG は 2400x2400 ですが絵が canvas いっぱいとは限らず、
インクの実範囲を測らないと図形が折り目でつながりません。

### 1b. 目印の色（`letter.html` の `MARKS`）

答えの3文字を矢印と同じ藍色にし、かく乱用の色文字を混ぜてある。
**文面を書き換えたら、`MARKS` の並び（「この学校」など）も合っているか
確かめること。**見つからない並びは、色がつかないだけで素通りする。

### 2. 座標を計算する

```bash
python3 tools/pamphlet/solve_overlay.py
```

このスクリプトは

- 対象3文字（こ・や・お）を通る直線を求める
- 図形が紙からはみ出さないか、文字に重ならないかを検査する
- **矢印が手紙の全文字と当たり判定して、狙った文字に最初に当たるか検証する**
- CSS の `background-position` と、パンフレット側の px 座標を出力する

を行う。`NG` が出たら、先頭の設計パラメータ（`EDGE_OFFSET` など）を
調整して再実行する。

### 3. 出力を貼る

- `js/letter-decor.js` の `puzzleLine` プリセット
- `tools/pamphlet/pamphlet.html` の「謎解きギミック」ブロック

の両方に貼り、PDFを作り直す。

### 4. 実際に重ねて確かめる

```bash
node tools/pamphlet/shoot_overlay.mjs out    # 便箋とA1面を撮る
python3 tools/pamphlet/verify_overlay.py out # out/overlay.png ができる
```

`overlay.png` で、2つの魔法陣がそれぞれ**1つの図形につながって見えれば成功**。

> ⚠️ **合成画像を「なんとなく合っている」で通さないこと。**
> ここは一度ひっかかっている。`shoot_overlay.mjs` が封蝋ではなく便箋の
> 真ん中あたりを座標でクリックしていたため、封筒が開かないまま撮れて
> しまうことがあった。閉じた状態の `.letter-content` は開いたあとと
> 寸法が違うので、背景に敷いた魔法陣の位置がずれる。それでも小さい画像で
> 見ると「つながっているように見えて」しまい、ズレたまま通ってしまった。
>
> いまは `open_letter.mjs` が封蝋（`#sealBig`）を直接クリックし、
> `.letter-paper.opened` が付くのを待ち、便箋が 3:4 であることを
> 確かめてから撮る（違えばエラーで止まる）。
> 目視で怪しいと思ったら、拡大して見るか、次のように
> 矢印の延長線と文字の当たり判定を重ねて描くと一発で分かる。

### つまずきやすい点

- **モチーフPNGは canvas いっぱいに描かれていない。** 本は 2400px 中
  y 0.28〜0.72 の範囲にしか絵がない。canvas の中心を線に合わせると
  本だけ線からずれる（実際にこれで一度失敗している）。
  スクリプトの `INK` テーブルがインクの範囲を持っている。
- **紙に刷る紋章は rotate(-51.98deg) しておく。** 参加者は紙を折り線の
  角度だけ回して置くので、刷った絵も一緒に回ってしまう。逆に回しておかないと
  向きが合わない。どちらも同心円を含むので気づきにくいが、
  六芒星・五芒星の頂点の向きを見れば分かる。
- **矢印は折り線に垂直にする。** 手紙の文字は斜め45°の格子状に
  並んでいるので、画面の真下に向けると真ん中の矢印が上の行の
  「ず」に先に当たってしまう。
